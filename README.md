# Moa Lindgren — Resume

Personal resume site, published via GitHub Pages.

**Live:** https://lindgrenmoa.github.io/moa-lindgren-resume/

## Structure

- `index.html` — the entire site (markup, styles, and content in one file).

## Updating

Edit `index.html` and push to `main`:

```
git add index.html
git commit -m "Update resume"
git push
```

GitHub Pages redeploys automatically after each push to `main`.
